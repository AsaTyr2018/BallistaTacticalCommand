# Contributing

Thanks for helping improve **Ballista - Tactical Command**.

## Local Setup

```bash
npm install
npm run start
```

For a user-friendly setup, run `setup.bat` and then `start.bat`.

## Development Guidelines

- Keep the interface compact and tactical.
- Prefer readable field-equipment styling over decorative UI.
- Keep gameplay text in English.
- Avoid changing unrelated systems when working on a focused feature.
- Run `npm run build` before submitting changes.

## Pull Requests

Include:

- What changed
- Why it changed
- How it was tested
- Screenshots for visible UI changes
