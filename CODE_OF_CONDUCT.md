# Code of Conduct

This project should be a constructive and welcoming space.

## Expected Behavior

- Be respectful.
- Give useful feedback.
- Assume good intent.
- Keep discussions focused on the work.

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Discriminatory language
- Deliberate disruption of project work

## Reporting

If a problem occurs, document what happened and share it with the project maintainer.
