# Ballista - Tactical Command

## First time

Double-click `setup.bat`.

This installs the required files and checks that the game can build.

## Start the game

Double-click `start.bat`.

The game opens in your browser at:

`http://127.0.0.1:5173/`

## Stop the game

Double-click `stop.bat`.

## If something goes wrong

1. Close the browser tab.
2. Double-click `stop.bat`.
3. Double-click `start.bat`.

If setup fails because Node.js is missing, install the LTS version from:

`https://nodejs.org/`
